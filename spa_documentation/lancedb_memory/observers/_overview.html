An observer here is a Gang-of-Four Observer: a small object with one method, on_turn_complete(user_turn, agent_turn, recalled, reply), that the agent calls after every turn finishes. Observers are how side effects — logging, archiving, cost tracking — get out of agent.py without the agent needing to know they exist. Every observer implements the TurnObserver protocol defined in ports.py.

Why observers instead of inline code

The agent's orchestration loop (embed → recall → call the model → store) is the same regardless of whether you're printing a recall summary to the console, writing turns to disk, or tallying token cost. Rather than hard-coding those concerns into the loop, the agent takes a single TurnObserver and calls it once per turn. What that observer actually does — nothing, print a line, archive to JSON, accumulate a running total, or all of the above — is decided at composition time, not inside the agent.

The five observers

  • Null Observer — the Null Object. Does nothing. Lets the agent run with no side effects and no None-checks anywhere the agent would otherwise ask "do I have an observer or not?"
  • Console Observer — prints one recall summary line per turn ([memory] recalled N turn(s) as context). Replaces the ad-hoc prints scattered through the legacy script.
  • Cost Observer — accumulates cost_usd, input_tokens, and output_tokens across the session from each AgentReply. Pure bookkeeping, no I/O.
  • Nexus Archive Observer — writes one JSON file per turn into the nexus directory. This is a write-only archive: nothing in the read path depends on it, so an emptied or missing nexus directory can no longer silently degrade recall (the bug the legacy script had). Its purpose is portability — raw turn text survives independently of whatever vector store is in use.
  • Composite Observer — fans one turn out to a list of other observers. This is how the agent runs with more than one observer at once (e.g. console + cost + nexus archive together) while still only ever holding a single TurnObserver reference itself.
