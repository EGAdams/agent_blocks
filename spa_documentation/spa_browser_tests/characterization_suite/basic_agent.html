Characterization Suite

spa_documentation/browser_tests/ — 21 modules, 1 test file, 1,203 lines

The only executable test suite in this repository. Six Playwright tests drive a real Chrome against a real server.py and pin down what the legacy app.js does today, so the strict-TypeScript rewrite under app/ can be checked against behavior instead of against memory.

Why this block exists

app.js is 1,301 lines and drives every piece of navigation in this SPA. Nothing under app/ is loaded by the browser yet. Before the first line of that rewrite reaches index.html, there has to be something that fails loudly when behavior changes — otherwise "the rewrite works" means "nobody has noticed yet".

What it is made of

  • One test file. legacy-navigation.test.ts, 141 lines, six tests: home nav, all five detail tabs, deep links with anchors, invalid-route fallback, embedded mode, and both canonical lessons.
  • Twenty-one modules, one directory each, wired through a single composition root — the only module allowed to name a concrete implementation.
  • A page object. Tests speak SpaPage; no test names a raw Playwright selector.
  • An abstract factory. PlatformProfile absorbs every Windows/WSL versus Linux difference, so no isWindows branch survives in a consumer.
  • Null Objects. The step dialog, the window focus call and the hold-open banner are objects that do nothing in a headless run, not flags checked inside a test.

Where it stands

npm test reports 6 passed, 0 failed in about eight seconds, and npm run typecheck passes across app/, app_tests/ and browser_tests/. Two things are open: the Chrome path is a hard-coded constant with no environment override, so a fresh checkout fails at browser launch; and the Update Documentation lifecycle — the largest single behavior in app.js — is still unpinned.

Open Construction Status for the five-stage plan, or Source for the test file itself.

A note on this folder's name

Every other documentation tree here mirrors a project one level up in agent_blocks. This one documents source that lives inside this repository, at spa_documentation/browser_tests/. The docs folder is called spa_browser_tests/ because browser_tests/ is already taken on disk by the source it describes.
