What this step is for Write down what app.js does today, in tests, before anything replaces it.

1. What this stage actually means

A characterization test does not assert what the code should do. It asserts what the code does, so a rewrite that changes behavior has to say so out loud. This stage is the safety net the whole TypeScript migration is supposed to fall into.
