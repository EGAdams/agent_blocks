2. What the three status words mean

Words like “done” drift over time, so on this plan each status word is tied to something you can go and look at: a file that is on disk, a command you can run, or a screen you can watch. Every item names its own. If you cannot open the thing it names, the status has not been earned yet.

StatusWhat it tells youWhere to look
Done The work is built, and something checkable was run against it — a test, a compile, a file you can open. The item's page has a “how to check this yourself” section. If that check fails or the file is gone, the item goes back to In progress.
In progress Part of it is built and part of it is not, and the item's page says which is which. Read that item's “what is still missing” section. That list is the current worklist.
Not started Nothing has been written for it yet. Only the outcome is described. Nothing to look at. If you do find code for it, the item was described wrongly and needs re-reading before anyone works on it.

3. The verified fact base

These are not recollections. Each line was checked against the working tree while this page was written.

  • voice_communication/conversation_agent/conversation_agent.ts declares one operation: submit( text, generation ) returning AsyncIterable<AgentEvent>. It is a type-only file — there is no implementation of it anywhere in TypeScript.
  • voice_communication/typescript_contracts/contracts.ts defines GenerationId = number and five AgentEventKind values: reasoning, assistant_text, tool, terminal, error.
  • npm run typecheck (tsc -p tsconfig.json) passes, so the declared contract is at least internally consistent.
  • claude_agent_adapter/ in the parent workspace is a real, working implementation of the same plug-in point in Python: ports.py holds the Protocol, adapter.py streams events out of claude-agent-sdk, and tests/test_adapter.py reports 4/4 passed offline with no API key.
  • letta_agent_adapter.ts is now class LettaAgentAdapter implements IConversationAgent, whose submit() is a stub that only throws — the shape exists, the behavior does not.
  • Three copies of the event shape have drifted: TypeScript's AgentEvent requires sessionId, voice_communication/pydantic_models/models.py requires session_id: UUID, and the Python adapter's local copy has no session field at all and only two of the five kinds.

5. The single next action

Not “the next area” — the next thing to type. Open Stage 2 › Reconcile the three AgentEvent copies from the section pages. It asks one decision: does AgentEvent carry a session id or not? Every later stage inherits that answer, which is why nothing downstream of it has been started.

6. How to read the rest of this plan

The section links show one level at a time. A page with child links opens into smaller items; a page without them is a leaf, small enough to finish and prove in one sitting. Selecting any item opens a lesson about that item alone: what it means, what exists, what is missing, how we will know it is done, and the next concrete action.

Construction Principle Move one narrow boundary from not started, to in progress, to verified. Then let the checks — not optimism — change its status to done.
