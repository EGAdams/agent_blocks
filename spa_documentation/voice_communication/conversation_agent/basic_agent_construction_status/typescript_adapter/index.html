What this step is for Turn LettaAgentAdapter from a throwing stub into a class the browser can actually use.

1. What this stage actually means

The Python adapter proved the plug-in point is implementable. It cannot be shipped to a browser. This stage produces the implementation that Toyota will actually hold at runtime — the first non-type-only code in this block.

2. What exists today

A shell and a promise: class LettaAgentAdapter implements IConversationAgent, whose submit() exists only to throw. Every other TypeScript file in this package is still type-only, so this stage also introduces the package's first emitted JavaScript.

3. What is still missing

All of it — the class, the stream translation, and the contract tests that keep the next adapter honest.

4. Why it is not started

The translation layer is written against the event shape. Starting before Stage 2's reconciliation lands means writing it, then rewriting it.
