What this step is for A concrete class satisfying IConversationAgent, holding its transport as an injected dependency.

1. What this item actually means

One class with one async generator method. The interesting constraint is what it must not do: it must not construct its own transport, read global configuration, or know that a UI exists. Its dependencies arrive through its constructor so that a test can hand it a fake and a composition root can hand it the real one.

Follow the Python adapter's shape — it is the reference implementation for a reason, and matching it keeps the two sides of the boundary legible to the same reader.
