# Expense reconciliation role

`expense_reconciler` checks the ledger-to-receipt direction: it asks the agent to read every MySQL `expenses` row in `/home/adamsl/rol_finances` and flag rows without a matching receipt image. This complements `receipt_scanner`, which looks for receipt files without matching rows. The role is prompt-driven; this change does not add a Python-side matching implementation or a generated report.

- `lancedb_memory/finance_team/roles.py` registers the new `AgentRole` with the existing DB connection briefing and a 60-turn limit. Its prompt scans jpg/jpeg/png files recursively in `readable_documents/receipts/`, `readable_documents/generated_spreadsheets/receipts/`, `receipt_parsing_tools/generated_spreadsheets/`, and `tools/receipt_scanning_tools/incoming_scans/` under the finance repo. It parses the vendor/date/amount filename convention (including itemized receipts), skips malformed names, and treats a row as unaccounted unless a parsed receipt has the same date, an amount within $0.01, and an overlapping vendor/description token. It instructs the agent to make no DB changes or other repo file changes, apart from `reports/unaccounted_expenses_report.md`. That report is specified to include totals, percentage and method breakdown, a newest-first table of unmatched expenses, and matching caveats. New constants hold the naming briefing and directory list for this role; the existing scanner definition was not changed.
- `lancedb_memory/finance_team/orchestrate.py` includes the role in the default parallel fan-out, keeps synthesis after the mappers, exposes it through `--only expense_reconciler`, and adds `--skip-expense-check` to omit it from the default run.
- `specs/3e3e181e_expense_reconciliation_agent.md` records the implementation plan and static verification steps. `adws/adw_sssf_config/sssf.config.yaml` also changes the builder model from `openai-codex/gpt-6-astra` to `openai-codex/gpt-6-sol` and sets `thinking: high`.

From `lancedb_memory/`, run `.venv/bin/python -m finance_team.orchestrate --only expense_reconciler` to run just this role, or use `--skip-expense-check` for the rest of the default team. For static checks without connecting to the DB, run `.venv/bin/python -m py_compile finance_team/roles.py finance_team/orchestrate.py` and `.venv/bin/python -m finance_team.orchestrate --help`; the latter should show the role in `--only` choices and the new skip flag. An end-to-end run requires the DB credentials described in the role briefing and agent SDK authentication; no execution results are included in the diff.
